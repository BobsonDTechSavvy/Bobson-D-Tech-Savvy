Personal portfolio site built with HTML, CSS, and vanilla JavaScript.

## Structure
- index.html        — Home
- about.html         — About (Bio, Education, Experience)
- skills.html        — Skill/Service
- certificates.html  — Certificate
- contact.html       — Contact
- /assets/css        — Stylesheets
- /assets/js         — Scripts
- /assets/images     — Images and badges
- /assets/docs       — CV and certificate PDFs
